# Tu buzón, conectado

Usa **webmail** para acceder desde el navegador o conecta una aplicación de
correo con **IMAP** para leer y **SMTP** para enviar. Ambos acceden al mismo buzón.

## Antes de empezar

Ten a mano estos datos proporcionados por quien administra tu buzón:

| Dato                 | Valor o ejemplo                                   | Para qué sirve                               |
| -------------------- | ------------------------------------------------- | -------------------------------------------- |
| Dirección de correo  | `user@<domain>`                                   | Enviar y recibir mensajes                    |
| Usuario del buzón    | Normalmente, tu dirección de correo completa      | Iniciar sesión y autenticar las aplicaciones |
| Dirección de webmail | [Abrir webmail](https://webmail.xn--tlo-fla.com/) | Acceder desde el navegador                   |
| Servidor de correo   | `mail.xn--tlo-fla.com`                            | Recibir por IMAP y enviar por SMTP           |
| Contraseña           | Se proporciona de forma privada                   | Iniciar sesión por primera vez               |

Algunos buzones antiguos tienen un nombre de usuario corto. Si es tu caso,
utiliza el usuario que te proporcionaron; no supongas que coincide con la dirección de correo.

## Elige el siguiente paso

- [Usar webmail](webmail.md): inicia sesión, lee y envía mensajes y encuentra la configuración.
- [Conectar con SMTP e IMAP](smtp-imap.md): configura una aplicación de escritorio o móvil.
- [Cambiar o recuperar tu contraseña](passwords.md): usa el portal de la cuenta.
- [Resolver problemas de conexión](troubleshooting.md): revisa el acceso, el cifrado y la entrega.

## Conserva el acceso a tu cuenta

Cambia la contraseña inicial por una frase de contraseña única. Si tienes la
autenticación de dos factores activada, usa una contraseña de aplicación en
clientes que no pueden pedir un código de tu autenticador. Solicita ayuda para
recuperar el acceso por el canal habitual de soporte de quien administra tu buzón.

La interfaz actual de webmail utiliza SnappyMail con la imagen de TLÁO.
Stalwart proporciona el servicio de correo. El acceso de administración de
SnappyMail es independiente del acceso a un buzón.
