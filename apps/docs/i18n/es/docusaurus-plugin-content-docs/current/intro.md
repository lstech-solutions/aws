## Conoce la plataforma

TLÁO significa **Tactical Layer for Action & Outcomes**: una capa táctica para
acciones y resultados. Conecta información no estructurada, como correos,
documentos y notas de reuniones, con herramientas de ejecución y pasos concretos.

Empieza por [por qué una capa importa](concepts/why-layer.md),
[qué significa «táctica»](concepts/why-tactical.md) y
[cómo las acciones generan resultados](concepts/action-outcomes.md).

:::info Configuración de tu buzón
La [guía de SMTP e IMAP](mail/smtp-imap.md) incluye el servidor compartido real,
los puertos y el cifrado. Sustituye `user@<domain>` por tu usuario de buzón.
Los buzones de distintos dominios pueden compartir el mismo servidor.
:::
