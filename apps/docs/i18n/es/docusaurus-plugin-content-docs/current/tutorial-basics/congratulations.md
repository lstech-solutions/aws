# ¡Felicidades!

Acabas de aprender los **fundamentos de Docusaurus** y de modificar la **plantilla inicial**.

¡Docusaurus tiene **mucho más que ofrecer**!

¿Tienes **cinco minutos más**? Explora el **[control de versiones](../tutorial-extras/manage-docs-versions.md)**
y la **[internacionalización](../tutorial-extras/translate-your-site.md)**.

¿Algo no está claro o falla en este tutorial? [Comunícalo aquí](https://github.com/facebook/docusaurus/discussions/4610).

## ¿Qué sigue?

- Lee la [documentación oficial](https://docusaurus.io/).
- Modifica la configuración con [`docusaurus.config.js`](https://docusaurus.io/docs/api/docusaurus-config).
- Añade elementos de navegación y pie de página con [`themeConfig`](https://docusaurus.io/docs/api/themes/configuration).
- Personaliza el [diseño y la estructura](https://docusaurus.io/docs/styling-layout).
- Añade una [barra de búsqueda](https://docusaurus.io/docs/search).
- Inspírate en la [galería de Docusaurus](https://docusaurus.io/showcase).
- Participa en la [comunidad de Docusaurus](https://docusaurus.io/community/support).
